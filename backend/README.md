# SoliFund : API (backend)

API NestJS 11 + Prisma 7 + PostgreSQL de SoliFund.

Installation, variables d'environnement (modèle : `.env.example`), migrations, lancement, tests et mise
en production : voir le [README à la racine du dépôt](../README.md).

```bash
npm run start:dev   # développement (http://localhost:3000, documentation sur /docs)
npm run test        # vérification TypeScript + tests unitaires
npm run test:e2e    # vérification TypeScript + tests de bout en bout (base de test séparée)
```
